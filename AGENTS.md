# Règles durables Artist

- Cette branche consolide le code vanilla existant ; préserver les projets et leurs personnalisations.
- Vérifier le dépôt et la version réels avant toute reprise : plusieurs copies existent sur cette machine.
- Les captures EX définissent le rendu cible ; les BUG décrivent les problèmes, pas une nouvelle DA.
- Aucune certification, identité, note, avis, horaire, économie ou promesse ne devient un fait par défaut.
- Les mutations utilisateur utilisent l'historique ; une réponse async obsolète ne remplace pas l'état courant.
- localStorage est local au navigateur. Ne pas qualifier un lien ou un PIN client de partage sécurisé.
- Renderer et export doivent rester cohérents. Préférer une primitive commune à deux correctifs divergents.
- Toute correction comporte un test adapté. Distinguer test de chaîne, comportement, navigateur et appareil réel.
- Ne jamais annoncer build/lint/typecheck si ces commandes n'existent pas ou n'ont pas tourné.
- Conserver les commandes tactiles de l'éditeur, les fonds lisibles, et une alternative reduced-motion.
- Une version et un changelog décrivent seulement ce qui a été livré ; travaux prévus explicitement non publiés.
